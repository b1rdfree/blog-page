# 出行准备清单

## 证件与钱

- [ ] 身份证
- [ ] 银行卡 / 少量现金
- [ ] 机票、酒店订单截图（离线保存）

## 电子

- [ ] 手机 + 充电器
- [ ] 充电宝（登机不超过 100Wh）
- [ ] 耳机
- [ ] 相机 + 备用电池

## 衣物

- [ ] 换洗衣物（按天数 +1 套）
- [ ] 外套（车上/飞机上冷）
- [ ] 拖鞋
- [ ] 雨具（南方必备）

## 洗护与健康

- [ ] 牙刷牙膏
- [ ] 防晒霜
- [ ] 常用药：感冒、肠胃、创可贴
- [ ] 晕车药（山路多的话）

## 出发前 1 天

- [ ] 确认天气
- [ ] 值机选座
- [ ] 家里断水电、倒垃圾
- [ ] 告诉家人行程
